# 工厂巡检日报 Agent（Inspection Daily Report Agent）

## 项目简介

本项目旨在构建一个**可稳定使用的工厂巡检日报生成工具**。
通过结构化输入巡检信息，自动生成符合现场使用标准的日报内容。

该项目聚焦于：

* 提高巡检记录整理效率
* 降低人工编写成本
* 提供稳定、一致的输出格式

> 核心目标：让一线人员**无需思考，即可生成可直接使用的日报**

---

## 核心特性

### 1. 结构化输入

通过固定字段约束输入内容，降低模型理解成本：

* 巡检时间
* 巡检区域
* 设备名称
* 运行状态（正常 / 异常）
* 问题描述
* 处理情况
* 备注

---

### 2. 标准化输出

自动生成统一格式的巡检日报，包含：

* 基本信息
* 设备运行情况
* 异常情况说明（按需生成）
* 处理情况
* 待跟进事项

输出风格稳定、简洁、符合工程记录习惯。

---

### 3. 稳定性控制（核心能力）

通过 Prompt 约束，实现：

* 禁止模型自由发挥
* 风险表达标准化
* 处理逻辑固定化
* 异常场景规则化

目标不是“更聪明”，而是“更可靠”。

---

### 4. 异常处理机制

系统内置基础规则：

* 输入缺失 → 拒绝生成并提示补充
* 状态冲突 → 自动忽略无效信息
* 信息过少 → 简化输出，不强行扩展

---

## 使用方式

### Step 1：复制 Prompt

使用 `prompt_v1.txt` 中的内容作为系统提示词。

---

### Step 2：输入巡检信息

示例：

```
【巡检时间】：2026/04/02
【巡检区域】：X1 CSF
【设备名称】：WCZM02
【运行状态】：异常
【问题描述】：管道未隔离，存在误操作风险
【处理情况】：未处理
【备注】：
```

---

### Step 3：获取日报

系统将自动生成标准格式日报，可直接使用或微调后提交。

---


## 设计原则

本项目遵循以下原则：

### 1. 可控优先于智能

不追求复杂推理，只保证输出稳定可靠。

---

### 2. 结构优先于内容

通过结构化设计降低模型不确定性。

---

### 3. 一致性优先于多样性

所有输出必须风格统一、表达固定。

---

### 4. 可用优先于完美

目标是“能直接用”，而非“最优表达”。

---
