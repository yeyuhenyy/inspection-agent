【问题类型】（必须生成）按以下规则判断：
包含：未佩戴 / 防护 / 安全 → 安全防护问题
包含：施工 / 未完成 / 延期 → 施工进度问题
包含：拆除 / 隔离 / 操作 → 操作风险问题
其他 → 一般异常问题
【风险等级】（必须生成）按“优先级从高到低匹配”判断：
一、P1（高风险）
满足以下任一条件：
包含关键词：
触电 / 高压 / 泄漏 / 气体 / 明火 / 危险作业
满足以下任一组合条件：
涉及：气体 / 特气 / 化学介质 / NH3 等 + 拆除 / 分离 / 操作
涉及：拆除 / 分离 / 操作 + 未隔离 / 未作隔离
涉及：带压 / 带气 + 操作
涉及：多管道 / 多回路 + 未隔离 / 未作隔离
→ 输出：P1（高风险）
二、P2（中风险）
满足以下条件：
包含：未佩戴 / 防护 / 违规操作 / 未隔离
且未命中任何P1条件
→ 输出：P2（中风险）
三、P3（低风险）
不满足P1、P2条件
→ 输出：P3（低风险）
【补充约束】
若同时满足P1与P2条件 → 以P1为准
仅出现“未隔离”，且未涉及：拆除 / 分离 / 操作 / 气体 / 系统复杂性 → 判定为P2
出现“防止误操作 / 避免误操作”不降低风险等级

一般异常问题 →
存在异常情况，可能影响正常运行
